# 打包与安装指南

本文档介绍如何在 macOS 上将 Privacy Metadata Cleaner 构建为 `.app`，并进一步封装为带有自定义图标、背景与签名的 `.dmg` 安装镜像。

## 一、准备工作
1. 安装最新的 Xcode 及其命令行工具（`xcode-select --install`）。
2. 安装 .NET 8 SDK 与 MAUI 工作负载：
   ```bash
   dotnet workload install maui
   ```
3. 准备 Apple Developer 签名证书（开发或分发证书均可）。使用 `security find-identity -p codesigning` 查看本机可用证书。
4. 准备一张 1024×768 的 DMG 背景图与一个 `.icns` 图标文件，分别命名为 `dmg-background.png` 与 `PrivacyMetadataCleaner.icns` 并放置在 `artifacts/dmg-assets/` 目录下。

## 二、生成 .app 包
1. 在项目根目录执行发布命令：
   ```bash
   dotnet publish PrivacyMetadataCleaner/PrivacyMetadataCleaner.csproj \
       -f net8.0-maccatalyst \
       -c Release \
       -o artifacts/publish
   ```
2. 发布完成后，`artifacts/publish/maccatalyst-arm64/Privacy Metadata Cleaner.app`（以及 `maccatalyst-x64`）即为可执行的应用。
3. 可选：若希望合并双架构，可使用 `lipo` 创建通用二进制：
   ```bash
   lipo -create \
       "artifacts/publish/maccatalyst-arm64/Privacy Metadata Cleaner.app/Contents/MacOS/Privacy Metadata Cleaner" \
       "artifacts/publish/maccatalyst-x64/Privacy Metadata Cleaner.app/Contents/MacOS/Privacy Metadata Cleaner" \
       -output "artifacts/Privacy Metadata Cleaner" && \
   cp "artifacts/Privacy Metadata Cleaner" "artifacts/publish/maccatalyst-arm64/Privacy Metadata Cleaner.app/Contents/MacOS/"
   ```

## 三、应用签名
在生成 DMG 前，先为 `.app` 签名：
```bash
codesign --force --deep --options runtime --sign "Developer ID Application: YOUR NAME" \
    "artifacts/publish/maccatalyst-arm64/Privacy Metadata Cleaner.app"
```
签名完成后可使用 `codesign --verify --deep --strict` 验证。

## 四、生成自定义 DMG
1. 运行仓库提供的脚本：
   ```bash
   bash scripts/create_dmg.sh \
       artifacts/publish/maccatalyst-arm64/"Privacy Metadata Cleaner.app" \
       artifacts/PrivacyMetadataCleaner.dmg
   ```
   - 脚本会：
     - 创建临时磁盘映像并拷贝 `.app`、`Applications` 快捷方式与背景图。
     - 配置 Finder 布局（自定义图标、背景、窗口大小）。
     - 使用 `hdiutil` 生成压缩后的只读 DMG。
2. 生成的 `artifacts/PrivacyMetadataCleaner.dmg` 即可用于分发。

## 五、DMG 签名与公证（可选但推荐）
1. 使用 Developer ID 证书签名 DMG：
   ```bash
   codesign --force --sign "Developer ID Application: YOUR NAME" artifacts/PrivacyMetadataCleaner.dmg
   ```
2. 使用 `xcrun notarytool submit` 进行公证，完成后利用 `xcrun stapler staple` 附加票据。

## 六、用户安装流程
1. 双击 `.dmg` 挂载后，将看到自定义背景界面，包含应用与 `Applications` 快捷方式。
2. 将 “Privacy Metadata Cleaner” 拖动到 `Applications` 快捷方式即可完成安装。
3. 首次运行时，如出现安全提示，可在 “系统设置 → 隐私与安全性” 中允许来自已识别开发者的应用。

按照上述步骤，即可完成从构建、签名到分发的完整流程。
