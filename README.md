# 5Xing 计算器

macOS 桌面计算器，支持多条算式输入、实时结果、备注与历史保存，可一键打包成可安装的 DMG。

## 功能
- 单行算式输入：限制回车换行，支持乘号 ×、除号 ÷ 以及快捷的 `*`、`/`、`x` 形式，实时计算结果。
- 标题与备注：每条算式默认生成“算式1/2/3…”标题，可填写备注，实时保存。
- 智能粘贴：可从剪贴板粘贴多行算式，自动拆分为多条并插入光标或追加新条目，自动清理全角字符和千分位。
- 合计统计：自动汇总所有有效行的数量与合计金额，输入即更新。
- 历史记录：保存本次计算，包含标题与备注，点击即可恢复到编辑区，支持清空与删除单条。
- 快捷键：`Shift+Enter` 新增条目，`Cmd/Ctrl+Enter` 一键保存本次计算。
- 本地持久化：自动记住未完成的算式、备注、云同步设置与历史。
- 云同步：支持 iCloud、OneDrive、Dropbox（或仅本地）选项，可手动/自动触发同步。
- 触控键盘：内置数字与运算符键盘，方便点击录入。

## 开发与运行
```bash
npm install
npm start
```

## 打包 macOS 安装文件
在 macOS 环境运行：
```bash
npm run build:mac
```
默认生成 DMG 安装包，位于 `dist/` 目录，可直接分发安装。
