# instPro Calculator

macOS 桌面计算器，支持多行算式输入、实时结果和历史保存，可一键打包成可安装的 DMG。

## 功能
- 多行算式输入：支持乘号 ×、除号 ÷，实时计算结果。
- 粘贴算式：可从剪贴板粘贴表达式或文本，自动插入到当前光标或新行。
- 历史记录：保存本次计算，点击即可恢复到编辑区，支持清空与删除单条。
- 本地持久化：自动记住未完成的算式与历史。

## 开发与运行
```bash
npm install
npm start
```

## 打包 macOS 安装文件
在 macOS 环境运行：
```bash
npm run build:mac
```
默认生成 DMG 安装包，位于 `dist/` 目录，可直接分发安装。
